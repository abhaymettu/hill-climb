Tidewater Release Notes

Tidewater is a command line tool that syncs a folder of notes to any git remote. Here is what changed in recent versions.

Version 2.4.0

October 21, 2026

  • New: tide watch syncs on every save instead of on a timer.
  • Conflicts now open in your editor with both versions side by side.
  • Fixed a crash when a note's filename contained an emoji.

Version 2.3.2

September 30, 2026

  • Large folders (10,000+ notes) start up four times faster.
  • Fixed: tide status showed deleted files as modified.

Version 2.3.0

September 2, 2026

  • New: encrypt individual notes with tide lock.
  • The config file moved to ~/.config/tide/config.toml. Old locations still work.
  • Dropped support for git versions older than 2.30.
